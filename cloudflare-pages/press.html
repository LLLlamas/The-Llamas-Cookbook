Description · 580 chars
Llamas Cookbook is an iPhone-native recipe app for serious home cooks. It's the only recipe app that runs two recipes in parallel in cook mode — each with its own active state and Live Activity timer in the Dynamic Island. On-device AI parsing turns TikTok captions and recipe blog URLs into structured recipes without sending data to a third party. A friends graph lets users browse each other's libraries and import recipes with attribution chains — every imported recipe carries the story of where it came from. Built by one developer over two years. Free. No IAP. iPhone only.

Long-form summary

Most recipe apps were designed for one job: bookmarking recipes from food blogs. Llamas Cookbook was designed for the moment you're actually cooking — and for how recipes move between people who know each other.

The headline feature is a true multi-recipe Cook Mode. Two distinct recipes can be active at the same time, each with their own step progress, ingredient list, and timer. Both timers show up side-by-side in the Dynamic Island. Pestle ships multi-timer within one recipe; Mela ships multi-recipe with switching; Llamas Cookbook is the only recipe app that runs both in parallel.

On-device AI parsing — powered by Apple's FoundationModels — turns TikTok captions, Instagram posts, and recipe blog URLs into structured recipes. Confidence falls back to a regex parser when the model is unsure, so the AI never returns garbage.

The friends graph is built on CloudKit. Users add friends, browse each other's published recipe libraries, and import what they'd actually cook. Each import is a deep copy with an attribution chain — your grandma's lasagna keeps her name on it, even three friends down the chain. When a friend imports your recipe, you get a silent push notification.

Cloud-permalink sharing lets users send any recipe via iMessage. The recipient opens a clean URL in Safari with photos, ingredients, and steps formatted properly. No app install required on the receiving end.

Llamas Cookbook is free at launch with no in-app purchases, no advertising, and no subscription. The cooking experience — Cook Mode, AI parsing, friends, sharing, the sourdough hydration calculator — is unpaywalled.

Three features worth reviewing

If you're reviewing or covering Llamas Cookbook, these are the ones that distinguish it from Paprika, Pestle, Mela, ReciMe, and the rest of the recipe-app category.

🍲🍞

Parallel Cook Mode

Two recipes, two cook states, two Live Activity timers — both visible in the Dynamic Island at the same time. Built on AlarmKit, so the timers ring through Silent mode and Do Not Disturb.

📨

Share to anyone, no app

Every recipe gets a Universal Link to a Cloudflare Pages function that renders an OG-tagged preview. Recipients open the recipe in Safari with photos and ingredients formatted cleanly. The cloud-permalink architecture means a friend who never installs the app can still receive and read a shared recipe.

👋

Friend graph with attribution

CloudKit-backed friends, asynchronous library browsing, recipe imports as deep copies. Every imported recipe carries an attribution chain — originally shared by, imported via, and you. Recipe genealogy as a first-class feature.

The iOS-specific technical posture

For tech-focused outlets covering indie iOS work, these are the structural decisions worth digging into.

SwiftData + custom CloudKit sync. SwiftData's automatic CloudKit opt-in silently fell back to in-memory because of .cascade delete rules and non-optional properties. Custom sync layer built on the CloudKit public DB for friends and sharing.

AlarmKit for cook timers. Lock-screen + Live Activity + Dynamic Island. A per-cook TimerLiveActivityRegistry manages multiple parallel cook sessions so two recipes can each own their own Live Activity.

On-device AI with regex fallback. FoundationModels parses TikTok / Instagram captions and recipe blog URLs. When model confidence is low, a regex parser catches the structure. Three-tier confidence ranking; the user never sees garbage.

System Share Extension. URLs from any iOS app route into a deep-linked import flow. Image files route through an App Group inbox to the main app.

Universal Links + Cloudflare Pages share previews. Recipes are addressed by a 6-character ID. Cloudflare Pages functions render an OG-tagged HTML preview. Photos served as separate CKAsset signed URLs via an image proxy.

About the developer

Lorenzo is a solo developer based in the US. He built Llamas Cookbook over two years out of frustration with recipes scattered across screenshots, browser tabs, and the iOS Notes app. The app ships small improvements every week or two — what's in users' hands today won't be the same app a month from now.

The llama mascot is built into the brand: every other recipe app is faceless, and Llamas Cookbook isn't. The character appears throughout the UI as a progress indicator, share-preview watermark, and Cook Mode companion.
